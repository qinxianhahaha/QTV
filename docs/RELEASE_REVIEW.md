# QTV 1.0.0 发布审查

审查日期：2026-10-10。此记录说明本次验证范围和结果，不代表形式化证明，也不承诺第三方平台接口长期不变。

## 覆盖范围

应用入口、关注与存储、窗口状态、四平台取流、播放器会话与恢复、弹幕、Cookie、图片与视频代理、局域网同步、配置导入导出、更新检查、依赖、打包、文档与许可证。

本次修复包括：随机本地端口与访问路径、图片代理域名及重定向约束、图片大小与超时限制、禁止任意协议启动、随机局域网配对码及关闭清理、配置排除登录凭据、B 站认证与弹幕错误处理、弹幕解压和递归上限、动态菜单文本处理及样式输入校验、旧更新源替换。

实机还发现了强化运行时下缺少 V8 JIT 声明的问题。现仅增加 `com.apple.security.cs.allow-jit`，保留强化运行时，并在发布校验脚本中检查此权限，避免只通过编译却在抖音签名时退出。依据：[Apple JIT 文档](https://developer.apple.com/documentation/Apple-Silicon/porting-just-in-time-compilers-to-apple-silicon)、[Tauri macOS 打包文档](https://v2.tauri.app/distribute/macos-application-bundle/)。

## macOS 实机验证

环境：Apple Silicon，macOS 27.0.1。所有数据仅为测试当时各直播源实际返回的结果。

| 场景 | 结果 |
| --- | --- |
| 旧配置迁移 | 本机新旧 WebKit LocalStorage 逐项一致；启动进入关注首页 |
| 主界面 | 深浅主题、960×540 / 1200×675 布局；排序和隐藏操作正常 |
| B 站 | 原生 HLS，实际画面 1920×1080 |
| 抖音 | FLV / H.264，实际画面 1920×1080，源标注 60 帧；修复后无签名引擎退出 |
| 斗鱼 | FLV / HEVC，实际画面 1920×1080，源标注 30 帧，平台返回蓝光 4M |
| 虎牙 | FLV / H.264，实际画面 1920×1080，源标注 60 帧 |
| 小窗 | 缩小、紧凑布局、置顶、退出恢复；位置与比例规则另有单元测试 |
| 播放信息 | 读取实际尺寸；点击面板外关闭；Escape 先关闭面板再退出播放 |
| 局域网共享 | 无配对码/错误配对码均返回 401，正确配对码返回 200；关闭窗口后监听端口关闭 |

Intel 包完成交叉编译、架构与签名验证；未在独立 Intel Mac 上完成运行测试。macOS 12 为声明的最低版本，本次没有在每个旧系统版本逐一测试。

## 已知限制与后续维护

RustSec 还报告 `adler`、`bincode`、`paste`、`proc-macro-error` 的维护状态警告。部分来自当前 Deno/V8 版本的依赖，部分来自 Linux GTK 构建链。`glib 0.18.5` 的 unsound 警告属于 Linux GTK 路径；本次只发布 macOS，不分发该运行路径。升级 Deno/V8 应另行验证四平台签名，不宜为消除提示而直接跨版本替换。

平台接口、匿名清晰度、线路和直播编码可能变化；“原画”不保证等于主播源画质。重试测试不能替代长时间弱网、断网与多显示器的完整压力测试。

发行版采用 ad-hoc 签名，尚未 Developer ID 签名及公证。局域网同步使用 HTTP，配对码是访问控制而非传输加密。整体许可为 AGPL-3.0-only，继承组件的来源见第三方说明。
