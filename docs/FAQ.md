# 常见问题

**为什么选“原画”还是不够清楚？**

“原画”是请求偏好，平台可能返回受限制的实际档位。请打开播放信息查看实际尺寸；QTV 不会把 720p 标成实测 1080p。斗鱼部分房间的接口会降到蓝光 4M，即使菜单存在更高档位。

**B 站需要登录吗？**

可以先匿名播放，QTV 会尝试匿名播放网关及可用候选；部分房间能够获得比普通匿名接口更高的分辨率。这不保证所有房间原画、固定帧率或今后一直可用。受账号权限限制的内容仍需要平台授权。

**Mac 仍然发热怎么办？**

高分辨率、高帧率、弹幕和直播编码都会影响负载。可以隐藏弹幕、降低画质并检查是否使用原生 HLS。设备支持时 QTV 会尝试高效解码，但没有绕过物理性能限制。

**为什么小窗不能随意拉成其他比例？**

窗口锁定 16:9，避免窗口切换和拖动时产生多余空白。直播本身若是竖屏或其他比例，保留其原始比例可能仍有留边；QTV 不强行裁切或拉伸直播画面。

**隐藏和取关有什么区别？**

隐藏只影响首页显示。进入管理列表，点击眼睛即可重新显示；取关则删除关注关系，可在短时间内通过撤销恢复。

**QTV 与 DTV 数据会互相覆盖吗？**

不会。二者使用独立的 macOS 应用标识。通过 JSON 导入可以迁移关注和设置。旧存储键仍有保留，用于兼容导出格式。

**打开安装包提示开发者无法验证？**

目前安装包还没有 Apple Developer ID 公证。请只从本项目 Releases 下载，核对 SHA256，并按 README 中的 Apple 官方流程单独允许此应用。也可以从源码自行构建。
